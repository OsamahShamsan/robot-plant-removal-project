# Autonomous Plant Removal Robot – Individual Work

## Overview
This repository contains my individual contributions to the group project, focusing on market research, requirement definition, and CAD modeling for a robotic system capable of autonomously identifying, locating, and removing unwanted plants.

## Structure
- `/docs`: Project documents (market research, RASI table, Gantt diagram, design notes)
- `/cad`: CAD sketches, 3D models, renders
- `/assets`: Visual diagrams, charts, reference images
